# Retail Sales & Store Performance Analytics

A portfolio project demonstrating retail data cleaning, KPI analysis, store performance diagnosis, and business recommendations using Python, SQL Server, and Power BI.

## Project Objective

Identify high-performing and underperforming stores, diagnose the drivers behind performance differences, and translate data-driven findings into actionable recommendations for retail management.

## Tools

- Python
- Pandas
- SQL Server
- Power BI
- DAX
- Git
- GitHub
